# Kamel IRZOUNI · Personal Website

Public static website for `https://kamelirzouni.github.io/`.

This repository contains the deployable front-end only:
- `index.html`
- `assets/`

## Stack

- HTML
- CSS
- Vanilla JavaScript

## Local Preview

You can preview the site locally with any static server.

Example:

```bash
python -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## Features

- Bilingual interface: French / English
- Dark and light themes
- Responsive layout
- Static deployment compatible with GitHub Pages

## Repository Scope

This public repository is intended for the website that is published online.
It should only contain assets and content that are meant to be publicly accessible.
